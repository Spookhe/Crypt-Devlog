# JoyCrypt Games Devlog: Enemy AI and World Design

**By Ethan Gapic-Kott**

Crypt is a first-person magic-caster roguelite where players explore procedurally generated dungeons, fight enemies, and collect loot. My main responsibilities on the project are the enemy AI and the Hub environment.

## What this devlog covers

**The design challenge:** building a large roster of enemies without building each one individually, and making sure they still feel different to fight.

**Enemy system:** three classes (Melee, Archer, Mage), each with nine elemental variants, built on a shared AI system so new enemies only need what makes them unique.

**The Hub:** a physical space players return to between dungeon runs, designed to grow with the player through NPCs and new functionality.

**Reflection:** whether the classes and elements actually create different gameplay, and keeping the shared system flexible as more enemy types are added.
